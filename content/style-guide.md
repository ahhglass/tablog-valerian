Внешняя ссылка выглядит иначе: [SvelteKit](https://kit.svelte.dev). Наведите на заголовок раздела — справа появится символ ¶ для копирования якоря.

## Блок кода и списки

Ниже — пример блока кода: моноширинный шрифт, отступы и сохранение переносов строк. Так оформляют команды, фрагменты конфигурации или короткие скрипты.

```
npm run dev

```

## Цитаты и нумерованные списки

Нумерованный список подходит для последовательных действий: сначала одно, потом другое. В тексте можно комбинировать [внутренние ссылки](/archive), **жирное начертание** и _курсив_.

1. Первый пункт
2. Второй пункт
3. Третий пункт

> Пример цитаты: блок для выделения важной мысли или отсылки к источнику в тексте записи. Курсив и приглушённый цвет отличают цитату от основного текста.

Обычная заметка: по умолчанию `variant="note"`. Внутри можно использовать **markdown** — жирный текст, [ссылки](/archive).

<Callout variant="tip" title="Подсказка для автора">

Совет с кастомным заголовком. Удобно для коротких пояснений, не вынося их в отдельный раздел.
