# Tablog

Минималистичная тема блога на SvelteKit.

## Установка

```sh
npm install
npm run dev
```

## Использование

Записи и страницы обрабатываются через mdsvex. Весь контент лежит в папке `/content`. Если у записи есть поле `date`, она считается постом блога. Без даты — статической страницей. Материалы с `draft: true` недоступны на сайте.

Общие настройки — в `/src/config.js`. Ссылки автора, темы и соцсетей задаются там же.

Проект можно подключить к любому API блога, отдавать статический или динамический контент и деплоить на разные платформы — см. [документацию SvelteKit](https://kit.svelte.dev/docs).
